# 首页性能优化计划

## 问题分析

通过代码分析，发现以下导致首页加载缓慢的问题：

1. **图片加载效率低**：

   * LazyImage 组件实现复杂，未使用浏览器原生懒加载

   * 图片缺少宽度和高度属性，可能导致布局偏移

2. **网络请求优化不足**：

   * 三个主要 API 同时请求，可能存在阻塞

   * 已登录用户会为每个网站单独调用 isFavorited API，造成大量请求

3. **资源加载策略不完善**：

   * 缺少资源预加载和优先级设置

   * 未充分利用浏览器缓存

4. **渲染性能问题**：

   * 可能存在不必要的重渲染

   * 缺少代码分割和按需加载

## 优化方案

### 1. 图片资源优化

* **使用浏览器原生懒加载**：将自定义 LazyImage 组件替换为原生 `loading="lazy"` 属性

* **添加图片尺寸**：为所有图片添加固定宽度和高度，防止布局偏移

* **优化图片格式**：确保使用 WebP 等现代图片格式

* **实现图片占位符**：为图片添加骨架屏或占位符

### 2. 网络请求优化

* **API 批量请求**：修改后端 API，支持批量获取收藏状态

* **减少初始请求数量**：考虑合并 getCategories、getWebsites 和 getFeaturedWebsites 为一个 API，并通过调用Supabase PRC函数优化

* **实现数据缓存**：使用 React Query 或 SWR 实现数据缓存和背景刷新

* **添加请求优先级**：对关键资源使用 `fetchpriority="high"`

### 3. 资源加载优化

* **预加载关键资源**：对首屏关键资源使用 `<link rel="preload">`

* **优化 CSS 加载**：将关键 CSS 内联，非关键 CSS 异步加载

* **减少不必要的依赖**：检查并移除未使用的依赖

* **启用 gzip/brotli 压缩**：确保服务器配置了适当的压缩

### 4. 渲染性能优化

* **实现代码分割**：使用 React.lazy() 和 Suspense 实现组件按需加载

* **减少重渲染**：使用 React.memo、useMemo 和 useCallback 优化组件渲染

* **优化虚拟列表**：如果网站数量较多，考虑使用虚拟列表

* **简化 DOM 结构**：减少不必要的 DOM 节点

### 5. JavaScript 执行优化

* **延迟加载非关键脚本**：使用 `defer` 或 `async` 属性

* **优化第三方库**：考虑按需引入第三方库

* **减少闭包和不必要的函数创建**：优化 JavaScript 执行效率

### 6. 缓存策略优化

* **实现 Service Worker**：用于静态资源和 API 响应缓存

* **设置适当的 Cache-Control 头**：为不同类型的资源设置合理的缓存策略

* **使用本地存储**：对不经常变化的数据使用 localStorage 或 sessionStorage

## 实施步骤

1. **图片优化**：

   * 替换自定义 LazyImage 组件为原生懒加载

   * 添加图片宽度和高度属性

2. **API 请求优化**：

   * 修改后端 API，支持批量获取收藏状态

   * 考虑合并相关 API，并通过调用Supabase PRC函数优化

3. **资源加载优化**：

   * 添加资源预加载和优先级设置

   * 优化 CSS 和 JavaScript 加载

4. **渲染性能优化**：

   * 实现代码分割

   * 优化组件渲染

5. **缓存策略优化**：

   * 设置适当的缓存头

   * 考虑实现 Service Worker
