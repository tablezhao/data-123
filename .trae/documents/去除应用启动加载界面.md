## 去除应用启动加载界面

### 问题分析
应用启动时显示加载界面是为了在初始化期间提供友好的用户体验，但用户希望去除这个界面，直接显示应用内容。

### 修复方案
1. **修改 appLoading 初始状态**：将 appLoading 的初始值从 true 改为 false
2. **移除加载界面显示条件**：删除或注释掉显示 AppLoadingIndicator 的条件判断
3. **确保初始化逻辑仍能执行**：保留 useEffect 中的初始化逻辑，但不阻塞应用渲染
4. **优化初始化流程**：确保初始化操作在后台执行，不影响应用的首次渲染

### 修复步骤
1. 修改 App.tsx 文件，将 appLoading 状态初始值设为 false
2. 删除或注释掉显示 AppLoadingIndicator 的条件判断
3. 保留 useEffect 中的初始化逻辑，确保认证和设置仍能正常加载
4. 测试应用启动流程，确保应用能正常运行

### 预期结果
- 应用启动时不再显示加载界面
- 直接显示应用的主要内容
- 初始化逻辑在后台执行，不影响用户体验
- 认证和设置仍能正常加载和更新

### 注意事项
- 确保应用在初始化完成前，能正确处理未初始化的状态
- 避免因去除加载界面而导致的白屏或闪烁问题
- 确保认证状态和设置在需要时能正确加载
