# 分类管理模块修复与增强计划

## 一、问题修复

### 1. 前台分类渲染逻辑修复
- **问题**：前台展示没有考虑分类的 `is_visible` 状态，所有分类都被显示
- **修复方案**：
  - 在 `CategoryWebsites` 组件中添加分类可见性过滤逻辑
  - 只渲染 `is_visible: true` 的分类
  - 只显示可见分类下的网站

### 2. 分类状态数据同步修复
- **问题**：后台修改分类状态后，前台可能没有实时更新
- **修复方案**：
  - 确保前台获取的分类数据包含最新的 `is_visible` 状态
  - 检查数据获取逻辑，确保没有缓存或过时数据

### 3. 数据库存储逻辑验证
- **问题**：需要验证隐藏操作是否被正确持久化到数据库
- **修复方案**：
  - 检查 `categoryService.ts` 中的更新逻辑
  - 确保 `is_visible` 字段被正确更新到数据库

## 二、功能增强

### 1. 热门推荐分类管理界面
- **需求**：添加热门推荐分类的可见/隐藏状态统一管理界面
- **实现方案**：
  - 在 `CategoryManagement` 组件中添加热门推荐分类管理功能
  - 实现热门推荐分类的可见性切换
  - 添加批量操作功能

### 2. 热门推荐分类状态同步
- **需求**：实现热门推荐分类状态变更的前后端数据同步
- **实现方案**：
  - 添加热门推荐分类的 API 接口
  - 实现前后端数据同步机制

### 3. 无缝集成
- **需求**：确保新功能与现有分类管理系统无缝集成
- **实现方案**：
  - 保持一致的用户操作体验
  - 复用现有数据处理逻辑
  - 确保代码结构清晰

## 三、实施步骤

1. **修复前台分类渲染逻辑**
   - 修改 `CategoryWebsites` 组件，添加可见性过滤

2. **检查并修复数据同步机制**
   - 验证后台 API 接口
   - 检查前台数据获取逻辑

3. **添加热门推荐分类管理功能**
   - 修改 `CategoryManagement` 组件
   - 添加热门推荐分类管理界面
   - 实现批量操作功能

4. **测试修复和新功能**
   - 测试分类可见性切换功能
   - 测试热门推荐分类管理功能
   - 测试批量操作功能

## 预期效果

- 分类可见性状态在前后端同步一致
- 前台只显示可见分类
- 后台可以统一管理热门推荐分类
- 支持批量操作热门推荐分类
